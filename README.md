# sistema_de_administracion_web

Este proyecto es un sistema de administración web diseñado para gestionar un e-commerce de productos. Ofrece funcionalidades tanto para usuarios invitados como para usuarios registrados y administradores, facilitando la experiencia de compra y la gestión del catálogo de productos.

## Descripción
El sistema de administración web es una solución completa para gestionar y operar un e-commerce de productos. La plataforma permite a los usuarios navegar por un catálogo de productos, agregar artículos al carrito, realizar compras, y mucho más. Los usuarios registrados tienen acceso a funcionalidades avanzadas como la gestión del carrito y la compra de productos, mientras que los administradores pueden gestionar pedidos y administrar el catálogo de productos.

El sistema está diseñado para diferenciar entre tres tipos de usuarios:

Usuarios invitados: Pueden explorar los productos disponibles pero no realizar compras.
Usuarios registrados: Pueden agregar productos al carrito, gestionar su compra y completar el checkout.
Administradores: Pueden registrar nuevos productos, editar los datos existentes y gestionar los pedidos recibidos.

## Características
- Catálogo de Productos: Visualización de todos los productos disponibles.
- Carrito de Compras: Funcionalidad para agregar, eliminar o modificar productos en el carrito.
- Gestión de Pedidos: Los administradores pueden ver y procesar los pedidos realizados por los clientes.
- Gestión del Catálogo: Los administradores pueden añadir nuevos productos, editar los existentes o eliminarlos.
- Roles de Usuarios:
  - Usuarios invitados: Solo visualizan los productos.
  - Usuarios registrados: Gestionan el carrito y realizan compras.
  - Administradores: Gestionan el catálogo y los pedidos.
- Interfaz Intuitiva: Navegación sencilla para todos los usuarios.
